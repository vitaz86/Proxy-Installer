# Proxy-Installer

Интерактивный Bash-скрипт для установки и настройки HTTPS-прокси (Squid) и SOCKS5-прокси (Dante) с защитой Fail2ban на Ubuntu 22.04 и 24.04.

## Возможности
- Поддержка Ubuntu 22.04 LTS и 24.04 LTS
- Устанавливает Squid (HTTPS) и Dante (SOCKS5) с защитой Fail2ban
- Опциональная установка Unbound DNS resolver для ускорения DNS-запросов
- Включает BBR TCP congestion control и сетевые оптимизации для лучшей производительности
- Автоматически настраивает правила Fail2ban для повышенной безопасности и защиты от взлома
- Интерактивный мастер с валидацией ввода для режима аутентификации, создания пользователей, белого списка IP и пользовательских портов
- Комплексная обработка ошибок и системные проверки (подключение к интернету, место на диске, существующие пользователи)
- Автоматическая настройка firewall (UFW) с обнаружением конфликтов и резервным копированием
- Резервное копирование существующих конфигураций перед перезаписью
- Опциональная очистка предыдущих установок
- Модульная структура кода для удобства сопровождения

## Требования
- Ubuntu 22.04 LTS или 24.04 LTS
- Права root

## Установка
Скрипт устанавливает необходимые пакеты (`squid`, `dante-server`, `apache2-utils`, `fail2ban`, `ufw`) и опционально `unbound`, затем проводит вас через настройку с комплексными проверками.
Для безопасности рассмотрите просмотр скрипта перед его запуском.
Эти команды скачивают (или клонируют репозиторий) и запускают скрипт с диска.

1. Скачайте скрипт или клонируйте репозиторий:
   ```bash
   curl -O https://raw.githubusercontent.com/vitaz86/Proxy-Installer/refs/heads/main/proxy-installer.sh
   ```
   или
   ```bash
   wget https://raw.githubusercontent.com/vitaz86/Proxy-Installer/refs/heads/main/proxy-installer.sh
   ```
   или
   ```bash
   git clone https://github.com/vitaz86/Proxy-Installer.git
   cd Proxy-Installer
   ```
2. Сделайте скрипт исполняемым, если нужно:
   ```bash
   chmod +x proxy-installer.sh
   ```
3. Запустите установщик:
   ```bash
   sudo ./proxy-installer.sh
   ```

Если вы хотите просмотреть скрипт перед запуском:
   ```bash
   nano proxy-installer.sh
   ```

НЕ ИСПОЛЬЗУЙТЕ однострочные команды bash, которые скачивают и передают установщик напрямую в bash и выполняют его за один шаг, потому что они не могут запускать интерактивные меню .SH скриптов!!!
Примеры (ПЛОХО для этого .SH скрипта):
   ```bash
   curl -fsSL https://raw.githubusercontent.com/vitaz86/Proxy-Installer/refs/heads/main/proxy-installer.sh | sudo bash
   wget -qO- https://raw.githubusercontent.com/vitaz86/Proxy-Installer/refs/heads/main/proxy-installer.sh | sudo bash
   ```

## Использование
Следуйте подсказкам для:
- Выбора режима аутентификации (гибридный, только пароль или только белый список IP)
- Добавления IP-адресов в белый список (с валидацией)
- Создания пользователей и установки паролей (с валидацией имен пользователей)
- Выбора портов для Squid и Dante (с валидацией номеров портов)
- Опциональной установки Unbound DNS resolver

Скрипт выполняет системные проверки (интернет, место на диске) и валидирует все вводы. После завершения отображает данные для подключения к настроенным прокси. Повторный запуск скрипта обнаруживает существующие установки и предлагает выполнить полную очистку перед переустановкой.

Для Unbound вы можете очистить DNS-кэш с: `sudo unbound-control flush_zone .`

## Устранение неполадок
- Если скрипт завершается с сетевыми ошибками, убедитесь в подключении к интернету.
- Проверьте логи: `/var/log/squid/access.log`, `/var/log/danted.log`, `/var/log/fail2ban.log`
- Статус служб: `sudo systemctl status squid danted fail2ban unbound`
- Firewall: `sudo ufw status` (резервная копия правил: `/etc/ufw/ufw.rules.backup`)
- Если порты заняты, выберите другие или освободите их.
- Если обнаружены конфликты firewall, отключите конфликтующие службы (например, firewalld).

## Кастомизация
- Перезапустите скрипт для изменения настроек аутентификации или портов.
- Ручная настройка может быть выполнена в сгенерированных файлах конфигурации (резервные копии создаются как .bak):
  - `/etc/squid/squid.conf` (и `/etc/squid/squid.conf.bak`)
  - `/etc/danted.conf` (и `/etc/danted.conf.bak`)
  - `/etc/fail2ban/jail.local` (и `/etc/fail2ban/jail.local.bak`)
  - `/etc/fail2ban/filter.d/dante.conf` (и `/etc/fail2ban/filter.d/dante.conf.bak`)
- Перезапустите службы после ручных изменений:
  ```bash
  sudo systemctl restart squid danted fail2ban unbound
  ```

## Деинсталляция
Запустите установщик снова и примите опцию очистки для удаления установленных пакетов, файлов конфигурации, созданных пользователей и правил firewall. Обратите внимание, что файлы резервных копий (.bak) сохраняются для восстановления.
